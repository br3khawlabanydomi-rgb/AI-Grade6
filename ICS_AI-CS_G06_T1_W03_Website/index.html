Structured Prompts to Complete a Task

Grade 6 · Main Course · Term 1 · Week 3 · Core + Lab, two 45-minute periods

Safeguarding and responsible use

Do not enter names, faces, voices, Emirates ID numbers, or other personal or sensitive information into any tool. Follow your teacher’s instructions. Use the printed or teacher-operated option; no student account is needed.

Starter

Activate: Show two prompts for the same task - a vague one and a structured one - and the two curated outputs they produced. Teach: Introduce a simple prompt structure: Goal, Context, Format. Model completing one class task with it. Apply: Pairs write a structured prompt for a defined task; the teacher runs it on the approved tool and shows the output. Check: Pairs judge whether the task was completed and write one adjustment. Learning objectives and success criteria

  • Use a structured prompt to complete a defined task with an AI tool.
  • Describe the input structure used and whether the task was completed.

I can…

  • I can write a structured prompt with a clear goal, context and format.
  • I can say whether the task was completed and why.
  • I can improve my prompt once to complete the task more fully.

Explanation and examples

A prompt is the instruction you give an AI tool, and because many AI tools are learning systems, the wording strongly shapes the result. A structured prompt states three things clearly: the goal (what you want done), the context (the details the tool needs), and the format (how the answer should look). A vague prompt leaves the tool guessing, so it often returns something off-target or incomplete. A structured prompt narrows the possibilities and makes the task far more likely to be completed. Prompting is not a one-shot skill - you evaluate the output against the task, then adjust the prompt to close the gap. This is the start of designing AI solutions: define the task, structure the input, check the output, and improve. Becaus e the tool can produce confident but wrong answers, you always verify the result and never include personal data in the prompt.

Source activity

Hands-on activity guide Overview: A guided structured-prompting session. Pairs write Goal-Context-Format prompts for a defined, non-personal task; the teacher runs approved prompts on a school-approved child-safe tool and displays outputs. Pairs evaluate completion, make one adjustment, verify, and run a risk check. Grouping / timing: Pairs, with teacher-mediated tool use at the board. Tool: A school-approved child-safe AI tool, operated by the teacher only; students write prompts on paper first. - Accountfree for students. All tool use is teacher-mediated on the board; no student logins; no personal data in any prompt. Facilitation steps: 1. Read the defined task and underline what 'complete' means. 2. Write a structured prompt with Goal, Context and Format. 3. Hand your prompt to the teacher to run on the approved tool. 4. Judge whether the output completed the task. 5. Make one adjustment to your prompt to complete it more fully. 6. Verify the output against the task and complete a quick risk check. Unplugged fallback: Use simulated-AI cards: pre-printed outputs for a vague prompt and a structured prompt so pairs practise structuring, evaluating and adjusting with no live tool. Formative assessment (aligned to the objectives) Formative check. • Targets: Directly checks 'uses AI tools with structured prompts to complete tasks' • Check: Task-completion log: structured prompt, output, 'task complete?' + one adjustment • Success criteria: Completes the task using a structured prompt and records one adjustment that improved completion. • Evidence: Task-completion log. • Feedback / adjustment: Provide a stronger prompt structure for incomplete tasks; extend to multi-part prompts. Tool use is teacher-mediated and safe. Differentiation Representation: Provide a Goal-Context-Format prompt frame with an example filled in. Action & expression: Students can dictate their prompt to a scribe or write it; evaluation can be spoken. Engagement: Use tasks rooted in UAE topics students care about (a short summary about Sheikh Zayed's tree-planting, a packing list for a desert trip). People of Determination: Offer a cloze prompt frame and reduce to completing one part at a time; allow verbal responses. EAL: Bilingual labels for Goal, Context, Format; sentence frames for the evaluation. Stretch / next tier: Ask students to add a fourth element (Audience) and show how it improved the output.
